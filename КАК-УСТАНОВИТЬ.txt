УМНЫЙ ЗАЙКА — как открыть приложение на телефоне

Это веб-приложение (PWA). После установки у него своя иконка на экране телефона, оно открывается
на весь экран без адресной строки, работает без интернета и сохраняет данные на этом устройстве.
Данные демонстрационные. Сервера и общей базы пока нет: у каждого телефона свои данные.

Чтобы приложение можно было установить, его файлы нужно выложить в интернет по адресу https://.
Бесплатно это делается через GitHub Pages:

1. Зайдите на github.com под своим аккаунтом.
2. Нажмите «+» вверху справа → New repository. Название: umny-zayka. Тип: Public. Create repository.
3. На странице репозитория нажмите «uploading an existing file».
4. Перетащите в окно ВСЕ файлы из этой папки (index.html, manifest.webmanifest, sw.js и три картинки .png).
   Нажмите Commit changes.
5. Откройте Settings → Pages. В блоке «Build and deployment» выберите Source: Deploy from a branch,
   Branch: main, папка / (root). Нажмите Save.
6. Подождите 1–2 минуты и обновите страницу. Сверху появится адрес вида
   https://ВАШ-ЛОГИН.github.io/umny-zayka/

Установка на телефон:
- iPhone: откройте адрес в Safari → кнопка «Поделиться» → «На экран Домой» → «Добавить».
- Android: откройте адрес в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Важно:
- Репозиторий Public виден всем, а значит и адрес приложения открыт всем. Для демо с примерными
  данными это нормально. Настоящие данные детей сюда вносить нельзя: для них нужна рабочая версия
  с сервером в Казахстане и входом по паролю (см. план запуска).
- Кнопка «Сбросить демо-данные» в приложении возвращает примерные данные.
- Курсы валют в приложении — снимок на 29.10.2026. Ежедневное обновление появится в рабочей версии с сервером.

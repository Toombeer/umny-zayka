# Умный Зайка

CRM для детского центра в виде приложения для телефона (PWA).
Адрес: https://toombeer.github.io/umny-zayka/

## Что умеет
- Группы, расписание, журнал посещений (кнопками или текстом: «все были, кроме Маши»).
- Ученики и семьи: добавление, изменение, удаление; остаток занятий; риск ухода.
- Заявки: воронка, причины отказов, перевод заявки в ученика.
- Счета с семейной скидкой, отправка счёта в WhatsApp со ссылкой Kaspi; оплаты наличными (со сдачей), Kaspi, переводом; долги.
- Расходы, прибыль, налог, выгрузка оплат и расходов в Excel (CSV).
- Закупки: список товаров и динамика цен.
- Калькулятор абонемента.
- Курсы валют НБ РК, обновляются каждый день (GitHub Actions → rates.json).
- Аналитика по заявкам, посещаемости и заполненности групп.

## Где хранятся данные
Только на устройстве, в браузере. Сервера нет. Делайте резервную копию: Настройки → «Сохранить резервную копию».
На iPhone данные приложения с экрана «Домой» и данные в Safari — разные хранилища: пользуйтесь одним и тем же способом.

## Установка на телефон
- iPhone: откройте адрес в Safari → «Поделиться» → «На экран Домой».
- Android: откройте адрес в Chrome → ⋮ → «Установить приложение».

## Файлы
- `index.html`, `app.js` — приложение; `sw.js` — работа без интернета; `manifest.webmanifest` и иконки — установка.
- `rates.json` — курсы валют; `scripts/update_rates.py` и `.github/workflows/rates.yml` — ежедневное обновление.

# Умный Зайка

Демо-версия CRM для детских центров: расписание, ученики, заявки, оплаты (наличные, Kaspi, перевод), закупки с динамикой цен, калькулятор абонемента, курсы валют НБ РК и маркетинг.

Это PWA: откройте сайт на телефоне и добавьте на экран «Домой». Данные примерные и хранятся только на устройстве. Не вносите сюда настоящие данные детей.
